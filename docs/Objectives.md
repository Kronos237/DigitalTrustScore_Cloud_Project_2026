# Objectives

1. Analyze the trust analytics and explainable AI literature relevant to cloud applications.
2. Identify useful trust indicators that can be extracted from a website or application profile.
3. Design a machine learning workflow to estimate a trust score from the collected indicators.
4. Apply explainable AI techniques to make the score understandable and defensible.
5. Plan an AWS-based deployment architecture that supports storage, monitoring, and reporting.
